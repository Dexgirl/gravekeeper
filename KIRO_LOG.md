# Kiro build log

How Gravekeeper was built with Kiro.

- **Automatic:** `.kiro/hooks/kiro-log.json` appends one line under **Log** every time a spec task finishes (time · spec · task · diff size). It is a command hook, so it costs zero credits.
- **By hand:** credits used (from `/usage`) at the end of each day, and every bug a property test caught.
